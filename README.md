# Prodigy Generative AI - Task 02

## Image Generation Using Pretrained Models

This project demonstrates AI image generation using a pretrained Stable Diffusion model.

### Technologies Used
- Python
- Stable Diffusion
- Hugging Face Diffusers
- PyTorch
- Google Colab

### Implementation
A text prompt is provided to the pretrained Stable Diffusion model, which generates an image based on the given description.

### Sample Prompt
A beautiful futuristic smart city with flying cars, green buildings, advanced technology, realistic digital art.

### Output
The generated image is saved as `generated_image.png`.
